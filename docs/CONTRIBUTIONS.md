# 开发分工

FlowForge 以华为云码道的需求拆解、主体开发与动画迭代为开发主线。成员裴家庆（Blu3_）负责场景方向、需求反馈、使用验收与提交。

| 环节 | 实际工作 |
| --- | --- |
| 需求与任务组织 | 码道形成场景编辑与仿真需求、实现方案及任务清单，经审阅后逐步实施。 |
| 主体开发 | 码道实现场景编辑器、仿真引擎主体、运行控制、指标界面和初版测试。 |
| 动画迭代 | 码道新增显示插值模块、分层Canvas和初版动画集成，区分显示坐标与模型状态。 |
| 辅助复核与扩展 | Codex完成规格与实现复核、后续缺陷修复、布局搜索、热图与A/B集成、校庆主题及交付整理。 |

码道的原始会话、改动列表与阶段交付保存在独立的码道使用证明中。完整历史分工和各轮日志另行归档；正文采用简洁的阶段说明，不逐次重复工具名称。

最终版本的整体检查为26个测试文件、324项测试通过，类型检查与构建通过。该结果对应最终项目；码道阶段交付的验证输出保留各自时间与版本。
