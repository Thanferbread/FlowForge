# FlowForge 技术架构

当前版本为 React + Vite + TypeScript 浏览器应用。源码、界面与默认示例可独立运行，不需要后端或付费API。开发过程见 [码道开发过程](DEVELOPMENT.md)，实际分工见 [开发分工](CONTRIBUTIONS.md)。

## 场景领域

`src/domain/` 定义地图、障碍、出入口、展位实体、服务格和队列。几何操作统一检查边界、重叠与结构约束；序列化与导入负责稳定数据格式，校验检查场景完整性和通路可达性。默认招聘会示例在 `src/scenarios/campusFair.ts`。

## 确定性仿真

`src/simulation/` 是不依赖DOM的纯计算层，负责种子随机、外生需求、路径搜索、人员状态、排队服务、单步推进和指标。固定场景、需求及参数产生相同核心结果。模型按离散时间步提交；报告保留场景、配置、事件、指标与快照。

## 显示与交互

`src/App.tsx` 组织场景提交、运行控制与异步任务生命周期；`src/components/` 提供编辑、属性、运行和方案对比界面。Canvas分离静态地图与人员层，以requestAnimationFrame插值相邻格心之间的显示位置；动画不修改模型状态和统计结果。

## 布局比较

`src/optimization/` 枚举展位包的有限合法正交平移。各方案使用相同外生需求进行配对实验，训练筛选后只对一个候选进行留出验证。未满足预设门槛时保留原布局，界面显示未采用候选并禁用应用按钮。热图来自真实占用采样，共用标尺。

## 运行与验证

`npm run dev` 启动界面，`npm run build` 生成可部署静态站。纯引擎与实际App交互由现有26个测试文件覆盖，共324项；`npm run simulate` 生成默认报告，优化实验命令见模块README。历史报告不随公开源码提交，可由脚本重新生成。

该模型用于活动场地方案比较，尚未以现实人群数据标定，不承担应急疏散或安全认证功能。
