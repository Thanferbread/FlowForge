# FlowForge 校园人流实验室

面向招聘会、展览和校园活动的场景编辑、人流仿真与布局实验工具。版本：1.0。

![FlowForge 校庆版实际运行界面](docs/images/flowforge-anniversary.jpg)

源码仓库：https://atomgit.com/Blu3__/FlowForge 。默认发布分支：`main`。

作品馆：[FlowForge 校园活动空间人流仿真与布局比较](https://gallery.developer.huaweicloud.com/gallery/007027b697800000)。

## 能帮你做什么

校庆集市、校园展览或招聘会筹备时，可以先把出入口、障碍与展位画进网格，观察假设访客如何行走、排队和离场，再用相同访客需求比较不同布局，给场地讨论提供直观依据。

首页以“校庆集市怎么摆，才更顺？”切入；展开“第一次来？3步体验”，可直接启动示例、打开热图、比较布局。点击指南内的按钮保持说明展开，再点标题可手动收起。手机先显示画布，再显示编辑工具；“作品详情”链接可查看官方作品介绍。

将鼠标停在指标名称或数值上，可查看含义、公式、单位和样本范围；也可以用键盘聚焦或在手机上点按指标名称。按 Esc、再次点击或点按说明外部可关闭。等待均值仅统计已开始服务者，吞吐统计服务完成人数；说明与实际引擎计算口径一致。

示例为假设场景，未使用校庆现场实测数据。搜索可能找不到改善方案；未通过复验时保留原布局。

2026-10-27校庆版：主应用与展览页采用上理120周年主题的红金暖白配色，加入原创环形轨迹和校园建筑意象。最新运行截图与响应式检查见 `evidence/08_anniversary/`，交付ZIP以“校庆版”单独命名。

## 下载后直接体验

从仓库下载 ZIP 后，先完整解压，再双击根目录的 **[打开FlowForge.html](打开FlowForge.html)**。建议使用桌面 Chrome 或 Edge；无需联网、安装 Node.js 或安装依赖。这个单 HTML 文件内嵌了真实应用的生产构建，包含场景编辑、仿真、热图与布局比较。

根目录的 `index.html` 是 Vite 开发入口，直接双击不能启动源码应用；修改源码时使用下方命令。完整交付包另含 `submission/展览页面/index.html`、`submission/离线体验/index.html` 和作品材料，交付材料不随公开源码上传。

## 从源码运行

需要Node.js，已验证24.17.0。首次安装执行 `npm ci`，随后 `npm run dev -- --host 127.0.0.1`，打开终端给出的地址。Windows若PowerShell阻止npm脚本，使用 `npm.cmd`。

在 AI 开发者空间中启动预览使用 `npm run dev -- --host 0.0.0.0`，再按空间提示打开5173端口的预览页面。

```powershell
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
npm.cmd run simulate
```

修改源码后运行 `npm.cmd run build:offline`，会先检查类型并构建，再更新根目录的 `打开FlowForge.html` 及完整交付包内的离线副本，并附上第三方许可。提交源码时一并提交更新后的根目录 HTML，仓库 ZIP 中的离线体验才会与源码保持一致。常规网站部署使用 `npm run build` 生成的 `dist/` 目录。

## 使用

开发采用码道的分阶段工作流：先形成需求、方案和任务清单，再完成场景编辑、仿真主体与初版平滑动画。通过具体文件改动与运行反馈持续迭代，过程见 [码道开发过程](docs/DEVELOPMENT.md)。

1. 默认载入32×22、6展位招聘会场景，可绘制障碍、出入口，整体拖动展位，设置队列长度和服务时长。
2. 点击“一键运行示例”，按seed42、H300、N180以16×运行；可用1×观察、暂停、单步、切速及取消。
3. 显示热图检查累计密度。指标基于已提交模型时间步；动画仅改变显示坐标。
4. “搜索更好布局”枚举整体移动1–3格的合法展位包，固定训练11/29/47、留出83/101。搜索上限H300/N180/1600格/12展位，默认评估8个候选，最多12个。
5. A/B面板显示同需求的原始布局与训练候选，并明确是否采用。推荐布局只有通过留出门槛后可应用。可导出场景、完整仿真及对比JSON。

网格首次打开、窗口变化及“重置视图”时按可用空间居中适配。手机支持触摸选择、拖动展位和涂障碍；放大后可开启画布工具条的“平移”拖动查看，关闭后继续编辑。页面其它区域可正常上下滚动。

## 本次真实结果

- 类型检查、27个测试文件/338项测试、生产构建通过。包含桌面画布适配、手机尺寸、触摸编辑、居中命中、两层对齐及指标说明交互的回归检查。
- 默认仿真300步、924事件、149服务完成、138人离场；浏览器与headless核心逐字段一致。
- 搜索72个平移方案，32合法、40非法；实评8个，24个因预算跳过；33次仿真/9900步。
- 训练最佳候选未通过留出接受门槛，本次保留原布局。不能将等待单项降低写成整体改善。

本地完整交付包保留 `evidence/` 日志与 `runs/` 历史报告；这些大体积材料不随公开源码上传。执行 `npm run simulate` 可在本机重新生成默认运行报告；执行 `npx vitest run --config vitest.optimization.config.mjs` 可重新生成配对搜索报告。
